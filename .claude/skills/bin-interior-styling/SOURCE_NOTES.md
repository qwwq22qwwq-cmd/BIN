# Source and Packaging Notes

## Confirmed rules consolidated here
- Preservation priority over styling.
- Original render as the design and geometry reference.
- Only explicit, localized changes are permitted.
- No unrequested redesign or movement of fixed elements.
- Restrained soft styling; no autonomous large furniture, rugs, murals, or main
  lighting additions.
- Photorealistic, natural, restrained visual treatment.
- Preserve camera, perspective, composition, and aspect ratio.
- 4K target and PNG preference, subject to actual tool capability.
- For style transfer, the new clay/massing image controls geometry while older
  renders guide style and atmosphere.

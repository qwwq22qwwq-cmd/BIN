# Quality Check — Before and After

## Before editing
- [ ] Identify the current base image.
- [ ] Identify the exact object, surface, or region to change.
- [ ] Identify the role of each reference image.
- [ ] Note geometry, furniture, materials, lighting, and camera elements to preserve.
- [ ] Record stated physical dimensions, module sizes, grain direction, and pattern.

## After editing

### Geometry and design
- [ ] Room layout and circulation remain unchanged.
- [ ] Wall, ceiling, beam, cove, curve, and opening geometry remain consistent.
- [ ] Doors, windows, cabinetry, niches, and fixed furniture retain their positions
      and proportions.
- [ ] No unrequested objects were added or removed.

### Local edit accuracy
- [ ] Only the requested object or surface changed.
- [ ] The edit stays inside the intended boundary.
- [ ] Adjacent and unmarked areas remain consistent with the base image.
- [ ] Removal or movement did not alter unrelated surrounding construction.

### Materials
- [ ] Color, texture, relief, sheen, and scale match the reference as closely as
      possible.
- [ ] Physical module dimensions are respected where specified.
- [ ] Vertical/horizontal direction and pattern orientation are correct.
- [ ] Repetition, seams, and joints look plausible at room scale.

### Lighting and image
- [ ] Original light direction, shadow placement, and tonal character are retained.
- [ ] No excessive yellow/orange cast, saturation, bloom, or artificial glow.
- [ ] Camera, perspective, composition, and aspect ratio are preserved.
- [ ] No unintended crop, stretch, text, border, logo, or watermark.

### Delivery
- [ ] PNG preferred when available.
- [ ] 4K target achieved only when supported and actually produced.
- [ ] Unverified properties or tool limitations are disclosed accurately.

# Style Profile — bin-interior-styling

This profile guides visual tone only. It never overrides project materials,
geometry, layout, or explicit instructions.

## Preferred visual character
- High-end modern residential interior.
- Warm, restrained minimalism.
- Natural and photographic rather than visibly synthetic.
- Low-to-medium saturation.
- Soft natural light and believable shadow.
- Visual breathing room; avoid unnecessary decoration.
- Controlled warmth; avoid excessive yellow or orange cast.

## Known style vocabulary
These are reference directions, not mandatory default materials:
- Warm milk-tea / beige mineral-paint tones.
- ICI white paint.
- Light oak and natural wood grain.
- Warm-white cabinetry and restrained warm lighting.
- Calm neutral textiles and tactile, realistic finishes.

Use a listed material only when present in the base design or requested.

## Reference transfer
With older finished renders and a new clay/massing render:
- New clay/massing render = geometry, layout, built-ins, furniture placement,
  openings, camera, and composition.
- Older finished renders = style, material language, color mood, and atmosphere.
- Do not copy unrelated geometry or objects from older renders.

Prefer a small number of believable details over a decorated scene.
